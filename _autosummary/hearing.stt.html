hearing.stt¶

Speech-to-text for hearing — now backed by the scribed transcription façade.

hearing no longer implements its own STT engines. It consumes scribed (one façade over many engines) and adapts scribed’s normalized Transcript/Segment spine to hearing’s TranscriptSegment data model. The rest of the architecture still sees only the STTEngine Protocol: transcribe(audio) -> segments and stream_transcribe(frames) -> segments.

The default engine is scribed’s faster-whisper backend (local, fast). Swap engines by changing the scribed backend= (e.g. "openai") — nothing downstream changes. See scribed’s scribed-choose-backend skill for the full engine landscape, pricing, and the local-vs-cloud decision.

Engines by friendly name (ENGINE_ALIASES, used by get_engine() and the CLI’s --engine):

  • whisper — faster-whisper, local, any CPU/GPU (default; hearing[whisper])

  • openai — OpenAI transcription API (hearing[openai], OPENAI_API_KEY)

  • deepgram — Deepgram Nova-3 (hearing[deepgram], DEEPGRAM_API_KEY)

  • mlx / parakeet — Whisper / Parakeet-TDT on Apple Silicon (hearing[mlx])

  • whisperx — WhisperX, aligned words + optional diarization (hearing[whisperx])

The last three are scribed backends that hearing itself contributes (hearing.backends); they are registered with scribed on first use.

hearing.stt.DeepgramSTT(*, model=None, **kwargs)[source]¶

Deepgram (cloud) engine — Nova-3 by default; model="nova-2" etc. swaps it.

Batch goes to Deepgram’s pre-recorded REST API (via scribed’s deepgram backend); the live path is scribed’s VAD-segmented stream over that batch call. Needs pip install 'hearing[deepgram]' and DEEPGRAM_API_KEY.

class hearing.stt.ScribedSTT(backend='faster-whisper', model_size=None, language=None, vad=None, options=dict())[source]¶

Bases: object

An STTEngine backed by scribed — the single engine hearing now uses.

Parameters:

  • backend (str) – scribed backend id ("faster-whisper" default, "openai", …).

  • model_size (Optional[str]) – optional model override forwarded to the backend (e.g. "tiny").

  • language (Optional[str]) – force a language code; None => auto-detect.

  • vad (Optional[VAD]) – utterance segmenter for stream_transcribe (default: scribed EnergyVAD).

  • options (Mapping[str, Any]) – extra backend kwargs forwarded on every call (e.g. {"diarize": True} for WhisperX/Deepgram); see the backend’s param_map for what it accepts.
